# Eesti liitsõnareeglid

## Põhireegel

Eesti keeles kirjutatakse liitsõnad **kokku**. Kui kaks (või rohkem) sõna moodustavad ühe mõiste, kirjutatakse need üheks sõnaks.

See on Claude'i jaoks üks kõige raskemaid reegleid, sest inglise keeles kirjutatakse enamik liitsõnu lahku ("field book", "plant protection", "soil sample").

---

## Kokkukirjutamine (tavareegel)

### Nimisõna + nimisõna

| Lahku (VALE) | Kokku (ÕIGE) | Inglise |
|---|---|---|
| põllu raamat | põlluraamat | field book |
| taime kaitse | taimekaitse | plant protection |
| muld proov | mullaproov | soil sample |
| silo mais | silomais | silage corn |
| sõnniku laotamine | sõnnikulaotamine | manure spreading |
| väetis plaan | väetamisplaan | fertilization plan |
| seemne segund | seemnesegu | seed mixture |
| põllu piir | põllupiir | field boundary |
| saagi koristus | saagikoristus | harvesting |
| muld hariminen | mullaharmine | soil cultivation |

**NB:** Liitumiskohas võib sõna vorm muutuda:
- muld → mulla- (omastav): mullaproov, mullatüüp
- põld → põllu- (omastav): põlluraamat, põllutöö
- vili → vilja- (omastav): viljavaheldus
- seeme → seemne- (omastav): seemnesegu

### Omadussõna + nimisõna (kui moodustavad ühe mõiste)

| Lahku (VALE) | Kokku (ÕIGE) |
|---|---|
| suur talu | suurtalu (kui tähendab konkreetset talu tüüpi) |
| puna ristik | punaristik |
| valge ristik | valgeristik |
| talve nisu | talinisu |
| kevad oder | kevadoder |

**NB:** Kui omadussõna kirjeldab nimisõna vabalt (ei moodusta ühte mõistet), on lahku: "suur talu" (talu, mis on suur) vs "suurtalu" (suurtaluniku talu).

### Nimisõna + tegusõna tuletis

| Lahku (VALE) | Kokku (ÕIGE) |

| mulla harimine | mullaharmine |

## Sidekriipsuga liitsõnad

### Millal sidekriips?

1. **Lühend + sõna:** GPS-signaal, NPK-väetis, pH-väärtus, UV-kiirgus, IT-süsteem
2. **Täht + sõna:** B-vitamiin, A-klass
3. **Number + sõna:** 3-tolline, 12-silindriline
4. **Väga pikad liitsõnad** (valikuline, loetavuse parandamiseks): taime-kaitse-vahendite-kasutamise-plaan — parem on ümber sõnastada!
5. **Võõrnimi + eesti sõna:** John Deere'i-tüüpi (kuigi "John Deere'i tüüpi" on ka OK)

### Millal MITTE sidekriips?

| ❌ Sidekriipsuga (VALE) | ✅ Ilma (ÕIGE) |
|---|---|
| taime-kaitse | taimekaitse |
| põllu-raamat | põlluraamat |
| muld-proov | mullaproov |
| väetis-plaan | väetamisplaan |
| silo-mais | silomais |

## Lahkukirjutamine (erandid)

### Millal kirjutatakse lahku?

1. **Pärisnimi + üldnimi:** Järva maakond (aga: Järvamaa), Tartu linn, Eesti Vabariik
2. **Ametinimetus:** peaminister, riigikogulane (kokku!), AGA: Vabariigi President (suurtähega, eraldi)
3. **Ladinakeelsed nimetused:** Triticum aestivum (lahku, kaldkirjas)
4. **Kui lahkukirjutamine muudab tähendust:**
   - "suurtalu" (talu tüüp) vs "suur talu" (talu, mis on suur)
   - "mustmuld" (mullatüüp: tšernozjoom) vs "must muld" (muld, mis on must)
   - "pikajuurseline" (botaaniline termin) vs "pikk juurseline" (grammatiliselt vale, aga punkt on: tähendus muutub)

## Keerulised juhud

### Kolme- ja neljaosalised liitsõnad

Kirjutatakse kokku, kui tähendus on üks mõiste:
- taimekaitsevahendiregister (taimekaitse + vahendi + register)
- maheviljelussertifikaat (mahe + viljelus + sertifikaat)
- pinnaseniiskusemõõtja (pinnase + niiskuse + mõõtja)

Kui muutub liiga pikaks ja raskesti loetavaks, sõnasta ümber:
- ❌ taimekaitsevahenditejääkidekontroll
- ✅ taimekaitsevahendjääkide kontroll VÕI pestitsiidijääkide kontroll
