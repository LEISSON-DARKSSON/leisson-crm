# Võõrsõnade kohandamine ja võõrkeele mõjud

Siin on reeglid, kuidas kohandada võõrsõnu eesti keelde ja kuidas vältida soome ning vene keele mõjusid.

---

## 1. Võõrsõnade käänamine

### Apostroofi reegel

**Põhireegel:** Apostroof (') lisatakse enne käändelõppu, kui sõna lõpeb:
- suurtähega: GPS → GPS**'i**, GPS**'iga**
- numbriga: Windows 11 → Windows 11**'s**
- võõrtähega/hääldusega, mis erineb kirjapildist: Google → Google**'i**

### Tavaline käänamine (ilma apostroofita)

Kui võõrsõna on eesti keeles kodunenud ja käändub nagu tavaline sõna:
- server → serveri, serverit, serveriga
- printer → printeri, printerit, printeriga
- traktor → traktori, traktorit, traktoriga
- kombain → kombaini, kombaini, kombainiga
- herbitsiid → herbitsiidi, herbitsiidi, herbitsiidiga

## 3. Soome keele mõjud

### Soomepärased sõnad ja konstruktsioonid

Claude'i treenimisel oli palju eestikeelset internetiteksti, kus soome keele mõju on tugev (eriti noortekeel, sotsiaalmeedia).

| ❌ Soomepärane | ✅ Eesti | Selgitus |
|---|---|---|
| mä | ma | Soome "mä" → lüheneb "mä" |
| sä | sa | Sama muster |
| joo | jah | Soome "joo" = jah |
| kiva | tore, kena | Soome "kiva" = tore |
| ookoo | okei, hästi | Soome "ookoo" |
| juttu | juttu (siin on OK!) | "Juttu" on ka eesti keeles osastav |
| igatahes | igal juhul | Soome "joka tapauksessa" otsetõlge |
| vaan | vaid, aga | Soome "vaan" |

### Soomepärased lauseehitused

| ❌ Soomepärane | ✅ Eesti |
|---|---|
| Minulla on | Mul on |
| Se on niin, et... | Asi on nii, et... |
| Miten sinä teed... (aga eesti) Kuidas sa teed nii, et... | Kuidas sa suudad... |

## 4. Vene keele mõjud

### Venepärased konstruktsioonid

Eesti keeles on ajalooliselt tugev vene keele mõju (nõukogude aeg). Paljud konstruktsioonid, mis tunduvad „normaalsed", on tegelikult otsetõlked vene keelest.

| ❌ Venepärane | ✅ Eesti loomulik | Vene originaal |
|---|---|---|
| omab tähtsust | on tähtis | имеет значение |
| omab õigust | on õigus, on õigustatud | имеет право |
| käesoleval ajal | praegu | в настоящее время |
| antud juhul | sel juhul, siin | в данном случае |
| enese poolt | ise, enda | с моей стороны |
| selle arvel | selle tõttu, sellest | за счёт этого |
| vaatamata sellele | sellest hoolimata, vaatamata sellele (mõlemad OK) | несмотря на это |
| teostama kontrolli | kontrollima | осуществлять контроль |
| teostama mõõtmist | mõõtma | осуществлять измерение |
| teostama parandust | parandama | осуществлять ремонт |
| esitama pretensiooni | kaebama, nõudma | предъявлять претензию |
| juhtima tähelepanu | tähelepanu juhtima / osutama | обращать внимание |
| rahuldama nõuet | nõuet rahuldama (sõnajärg OK mõlemal) | удовлетворять требование |

### "Omama" — probleemverb

"Omama" on eesti keeles sageli venepärane. Põhireegel:

| ❌ Venepärane "omama" | ✅ Eesti loomulik |
|---|---|
| Omab suurt tähtsust | On väga tähtis |
| Omab kogemust | Tal on kogemust |
| Omab õigust | Tal on õigus |
| Omab head maitset | Tal on hea maitse |

**Erand:** "Omama" on OK, kui räägitakse füüsilisest omamisest: "Ta omab 100 hektarit maad" — kuigi "Tal on 100 hektarit maad" on parem.

### Kantseleikeele mõjud (nõukogudeaegne bürokraatiakeel)

| ❌ Kantseleikeelne | ✅ Normaalne eesti keel |
|---|---|
| nimetatud isik | see inimene |
| eelpoolöeldu | eelnev, see |
| allpool mainitud | allpool nimetatud / järgnev |
| lähtuvalt eelöeldust | seepärast, selle tõttu |
| sellest tulenevalt | seega, seetõttu |
| vastavuses eespool märgituga | nagu eespool öeldud |
| tutvudes materjalidega | materjale lugedes |
| kontakteerudes | ühendust võttes |

## 5. Inglise keele mõjud

### Inglise sõnajärg eesti lauses

| ❌ Inglise sõnajärg | ✅ Eesti loomulik |
|---|---|
| See on väga tähtis | Väga tähtis on see (rõhk!) |
| Ma olen olnud siin 3 aastat | Olen siin olnud 3 aastat |

| Inglise | ❌ Otsetõlge | ✅ Eesti |

| It makes sense | See teeb mõtet | On mõtet, on mõistlik |
| At the end of the day | Päeva lõpus | Lõppude lõpuks |
| In terms of | Terminites | Mis puutub, seoses |
| Based on | Baseerudes | Põhinedes, lähtudes |
| According to | Vastavalt | ... järgi, ... kohaselt |
| In the long run | Pikas jooksus | Pikas perspektiivis, edaspidi |
| On the other hand | Teiselt käelt | Teisalt, samas |
| As a matter of fact | Fakti mõttes | Tegelikult |
| To be honest | Et olla aus | Ausalt öeldes |
| More or less | Rohkem või vähem | Enam-vähem |
